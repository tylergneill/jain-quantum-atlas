Jain Quantum Atlas About

About this Atlas

A browsable index of the Jain eLibrary, an online library of Jain literature run by JAINA's education arm, as served by its two public faces: jainqq.org ("Jain Quantum"), a full-text search engine that publishes each item's OCR text, and jainelibrary.org, whose open API carries the richer metadata. This Atlas hosts no text; every item links back to Quantum's viewer.

What is and is not counted

The universe is the union of the two catalogues on their shared six-digit serial. An item has text when Quantum serves a booktext for it. An item is measured when that text has been fetched and its bytes counted; on the first build that is the Sanskrit-only slice, so the byte figures are a floor, not a total. The "TXT only" toggle on the main page hides everything without a public text.

Where Quantum stops

Quantum's catalog and text index end in 2022, and the library's OCR pipeline appears to have stopped with it. Items the library has accessioned since (about a fifth of it by count) are listed here from the API alone, flagged API only, with no public text and no size.

Growth

Every API record carries the day it went online, so the growth series is measured from the library's own stamps: months, to ; items known only to Quantum carry no date. The text series flattens after 2022 for the reason above.

Caveats

  • The text is OCR, with its noise still in. The furniture rules remove the digitising libraries' stamps and page numbers and nothing else.
  • "Sanskrit" per the catalogue includes many books with Hindi apparatus in the same script, and the language field's convention changed around 2023, so any Sanskrit is the stable grouping.
  • Classification on the source is mostly by script and format; subject tokens exist on some records but are not surfaced on either site.
