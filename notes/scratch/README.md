# scratch/

**Tasks in flight.** A new task is written here — a plan, a scoped design, a
measurement under way. When it finishes, any insight worth keeping is promoted
into a top-level `notes/*.md` about the structure it explains (or into a code
comment beside it), and **the scratch file is deleted.**

Nothing is kept because it was expensive to write.

**Check any of it against the code before acting** — these documents stopped
being maintained when their status line was written, and where one contradicts
the pipeline, the pipeline is right.

| File | Status |
| --- | --- |
| `todo.md` | live — the backlog spine. Every open item lives here; the top-level `notes/*.md` are the evidence behind them, not separate lists. |
